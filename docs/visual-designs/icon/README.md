# Lyra Icon & Color Palette Specification

### Dark Theme (`lyra-dark-*`)
| Element | Hex | Role |
| :--- | :--- | :--- |
| Background | `#000000` | Pure Black Canvas |
| L Monogram | `#FFFFFF` | Primary Architectural Mark |
| Parallel Harp Strings (`.string-1` / `.string-2`) | `#D2D8E2` | Cool Silver Strings |
